# 同车 · On the Same Bus

一个关于陌生人如何理解彼此，以及这些理解如何塑造彼此经历的纯文字短篇游戏。

**[中文试玩](https://along-the-way-jam-1023.fitcat.chatgpt.site/) · [English demo](https://along-the-way-jam-1023.fitcat.chatgpt.site/en.html) · [English README](README.md)**

## 我的设计初衷

我想通过游戏机制表达一个问题：我们体验到的世界，有多少来自眼前实际发生的事，又有多少来自我们预先相信、预测和理解的世界？

尤其在面对另一个人时，我们看到他的动作，却不知道他的处境。他突然起身，可能是在回应我，也可能只是腿麻了。他往旁边挪，可能是在疏远，也可能是在让位。我们暂时分不清，却仍然必须决定怎么做。

我希望游戏围绕日常中每个人都有的小小决定权展开：收包、挪脚、移开目光、留出空间、捡起一张小票。我的理解影响行动；我的行动又成为对方理解我的材料。双方由此共同塑造一段经历，同时也都拥有与对方无关的生活。

这个想法也来自对同理心减弱、人与人越来越难理解彼此的关心。我希望把这种关心放进一次普通的陌生人相遇，让玩家在结束时产生这样的感受：**“原来还有另一种解释，我想重新理解这段经历。”**

## 机制怎样服务这个想法

玩家坐在夜班公交的陌生人旁边。关键节点先选择一种暂时理解，再选择实际行动。NPC 也会提出几种解释、采用其中一种，预测玩家下一步会怎样，再选择自己的行为。这个行为直接成为下一轮玩家看到的事情。

玩家的内心理解不传给 NPC。它通过玩家自己选择的动作影响后续。NPC 的个人处境在开场就确定，一些行为会回应玩家，一些有独立原因。模型不能在结尾临时补背景，把任何事情都解释得通。

双方确认某次交流指向彼此时，故事立即结束；也允许始终没有搭上线，各自离开。没有善恶、人格或亲密度评分。结尾揭示过程中的双方记录，允许玩家回看未被自己想到的解释。

## 当前原型

- 中英文纯文字界面，最多八个场景节点，三组固定初始处境。
- 玩家选择预写的解释与行动；NPC 由 Gemini 生成候选解释、预测及选择。
- 环境事件、合法动作、动作呈现文字与结束条件由规则维护。
- NPC 每轮由一次结构化请求生成完整决策；并未拆成多个独立思考阶段。
- 回看实际选择与未选项、比较预测与后续行为，支持下载记录和回到节点重走。
- 没有模型服务时明确标注离线规则试玩。

## 本地运行

需要 Python 3.9 或更新版本，无需安装 Python 第三方包：

```sh
cd prototype
python3 server.py
```

在隐藏提示中输入自己的 Gemini 凭据，打开 <http://127.0.0.1:8766/>。英文为 `/en.html`。也支持由环境变量提供 `GEMINI_API_KEY`；服务不会自动读取 `.env` 文件。

离线试玩可直接打开 `prototype/dist/index.html`，或用静态服务器提供 `prototype/dist`。

检查及英文生成需要 Node.js 与 Python：

```sh
python3 prototype/build_languages.py
node prototype/test.cjs
node prototype/test_languages.cjs
```
